## 已知問題

- 640×480 失敗截圖中，小 Tag 只有約 10–12 px 寬。在目前內建參數下讀到 0 個。曾在離線實驗比較放大與自適應閾值設定，這些調整尚未進入交接版。
- 牌面分類依賴固定格位、明暗對比和清楚的正面 Tag。移位、光線變動、反光及手遮擋會造成未知或延遲。
- `front_seen` 代表首次確認到正面。由於遊戲面板只消費 `flip_up`，開局應等所有白背格位建立穩定 `down` 再翻牌。
- `time_s` 是程式的相對時間。相機模式以處理時間記錄，影格佇列會丟掉過時影格。另錄音訊或外部錄影需要同步。
- 目前規則針對一人一局八張牌。多玩家、任意牌組、移走或重排格位後的行為尚未驗證。
