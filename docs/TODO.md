# 待辦與驗收

| 優先級 | 可分派任務 | 輸入與交付 | 驗收標準 |
|---|---|---|---|
| P0 | 驗證一局完整實體操作 | 以現有 CLI 使用外接相機錄製一局，附人工逐事件標註和實際解析度。 | 報告四對是否正確、失配後是否等兩張蓋回、Q/D 是否可用、CSV 是否可讀。逐筆核對翻開與蓋回的牌號、格位及順序。 |
| P1 | 獨立事件評估程式 | 從人工標註與 `session_game.csv` 匹配事件類型、格位、牌號和時間。輸出逐項差異及統計。 | 同一人工事件只可配對一次。支援額外輸出、漏報、時間差和未知牌號，容許時間窗可設定，並附測試範例。 |
| P1 | 回合與行為摘要 | 新增離線分析腳本讀取時間軸，輸出 `round_summary.csv`。 | 用下列規則重建：兩個不同未配對格位、失配後等待蓋回。每回合列出兩張牌、時間、是否配對與先前指過哪些格。異常或漏事件須保留可核對的狀態。 |
| P1 | 建立有聲樣本與對時 | 同一局的有聲原始影片、同步點及人工核對的時間；可由 Whisper 或既有語音工具輸出起訖秒數和文字。 | 注明同步方法與偏移，至少一段「說水果名→指格→翻牌」可回到原始影片逐項核對。離線腳本不改現有事件格式。 |
| P2 | 教師標註與提示驗證 | 請幼教組定義可觀察線索，附正反例和一種可驗證的提示。 | 能從一局重播找出線索對應的事件，並明確說明何時觸發提示。用人工標註核對，不能只以配對成功就推論使用了特定策略。 |
| P2 | 頭部朝向原型 | 獨立輸出頭部粗略朝向區域與時間，允許未知。 | 人工標註數段左右轉頭及離開影像情境，同一局時間可對齊，清楚說明無法可靠判定精確注視格位的片段。 |

交接先統一使用同一局人工答案。影片、聲音與標註素材儲存於隊內授權位置，由負責人分享可使用的非私人案例。驗收步驟見 [TESTING](TESTING.md)。

P0 沿用 [SETUP](SETUP.md) 已跑通的正式指令及原八張牌。640×480 不列入交接驗收，只有正式模式再次遇到漏讀或取圖異常時才開故障排查。
